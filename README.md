# NurseryLedger

A Linux-based C++17 command-line application for managing nursery fees, recording payments, and tracking outstanding balances.

## Motivation

This project is inspired by my family's nursery, where I witnessed the challenges of managing administrative and financial records.

I wanted to develop a simple and reliable tool that could help nursery administrators organize monthly fees, track payments, and identify outstanding balances.

## Project Goals

- Register children and their enrollment dates.
- Manage monthly nursery fees.
- Record payments made by cash or bank transfer.
- Track partially paid and unpaid fees.
- Generate monthly financial summaries.
- Preserve records between application runs.

## Scope

The first version focuses on fee management and payment tracking.

Employee wages, operational expenses, and inventory management are potential future extensions.

## Technology

- C++17
- Linux
- CMake (planned)
- Python component tests (planned)
- C++ unit tests (planned)
